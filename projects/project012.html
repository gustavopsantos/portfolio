About

This project is a WIP project.

It has been developed by me, as a dependency for a networking project. Anvil will be responsible for serializing and deserializing the information packages that will be sent over the network.


Features

  • Compact Payload
  • 3 times faster than newtonsoft json
  • IL2CPP Friendly (No Reflection.Emit or ILGenerator.Emit)
  • No decoration needed
  • Nested layout serialization

Supported Value Types

  • Bool
  • Byte
  • Char
  • Double
  • Float
  • Int
  • Long
  • Sbyte
  • Short
  • Uint
  • Ulong
  • Ushort
  • Enum (Any Underlying Type)

Supported Reference Types

  • Type
  • String
  • Object
  • List (Of Any supported element type)
  • Array (Of Any supported element type)
