About

An asset that makes it not only possible, but easy to implement the location of a game or application made on unity.


Features

  • Tree View Editor
  • Duplicate
  • Copy
  • Paste
  • Move
  • Supports Multiple Languages running at same time (Eg. English for voice and Portuguese for Interface)
  • Keyboard Navigation
  • Translation Key Baking
  • Search
  • Value Preview
  • EntryID Type Attribute with filtering to improve usage
  • Endonym to Exonym matrix (necessary when multiple languagues are running)
  • Fully Configurable Locale Sources
  • Missing Value or Unset Source Warning
  • Configurable Visible Language Edition Columns
  • Undo & Redo

Supported Types

  • Folder
  • String
  • Font
  • AudioClip
  • Sprite
  • Texture
  • Prefab
  • Object
  • Incredible easy to extend to support other types
